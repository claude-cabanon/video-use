# video-use

- Open-source tool to edit videos with Claude Code: raw footage in a folder, chat, `final.mp4` out. Python package `video-use`: `helpers/` (editing primitives), `skills/` (Claude-facing skills), `static/` (assets).
- This repository is public. Never commit personal paths, footage, credentials, or material from another repository.
- Helpers must be composable and make file writes explicit in their name and docstring.
- Skill trigger wording is behavior: treat description changes as behavior changes.
- Commit format: `type: what and why`. Never push without explicit user confirmation.
